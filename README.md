# 이종완의 주식 분석 대시보드

Python과 Streamlit로 만든 KRX × OpenDART 주식 분석 앱입니다.
일별 주가·거래량, 이동평균·RSI, 시장 요약, 분기 실적, 재무 지표,
배당, 공시 원문, 관심종목 조건검색을 제공합니다.

## 시작하기

Python 3.10 이상이 필요합니다. 권장 버전은 Python 3.12입니다.

```bash
git clone https://github.com/jwsslee/db_jwlee.git
cd db_jwlee
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

브라우저에서 `http://localhost:8501`을 엽니다.
`python app.py`가 아닌 `python -m streamlit run app.py`로 실행합니다.

`app.py` 맨 위의 두 상수에 각 키를 입력합니다.

```python
KRX_API_KEY = "여기에_KRX_인증키"
DART_API_KEY = "여기에_OpenDART_40자리_인증키"
```

**이 저장소는 공개 저장소입니다. 실제 키를 붙여넣은 app.py는 로컬에서만 사용하고,
키가 들어간 파일을 GitHub에 커밋하거나 업로드하지 마세요.**
저장소에 저장된 코드는 빈 키만 포함합니다.
코드를 수정하지 않을 경우 같은 이름의 환경변수 또는 `.streamlit/secrets.toml`도
지원합니다. 값의 우선순위는 상수 → 환경변수 → Streamlit secrets입니다.

### 첫 실행 순서

1. 왼쪽 **연결 진단 → 연결 진단 실행**에서 API별 승인·인증 결과를 확인합니다.
2. **대시보드**에서 종목명 또는 코드를 검색합니다.
3. **선택 종목 분석 불러오기**를 누르면 해당 종목의 일별 이력과 재무·공시를 조회합니다.
4. 52주 범위가 필요하면 차트 기간을 **12M**으로 변경하고 다시 불러옵니다.
5. 관심종목은 최대 5개를 선택한 뒤 **관심종목 재무정보 조회**를 눌러 비교합니다.
6. **재무 상세**, **공시** 화면에서 더 긴 실적과 공시 목록을 확인합니다.

키가 없어도 **디자인 미리보기**를 명시적으로 선택하면 가상의 화면을 볼 수 있습니다.
실제 조회에 실패했을 때 미리보기 데이터로 자동 전환하지 않습니다.

| OpenDART 정식 endpoint | 개발 환경에서 잘못된 테스트 키의 HTTP 200 / 상태 010 응답 확인 |
| 완성한 앱의 HTTP 클라이언트 | 위 401·010을 키 노출 없이 서비스별 오류로 변환하는 것 확인 |
| 사용자 개인 키로 정상 자료 조회 | **미검증**. 키가 제공되지 않았으므로 실행 환경에서 연결 진단 필요 |

외부 서버, API 승인·유효기간, 허용 IP, 이용 한도 때문에 **항상 접속 오류가 없다고
보장할 수는 없습니다.** 프로그램은 실패 항목을 명시하고 나머지 화면을 유지합니다.
화면과 테스트에 쓰는 가상 데이터는 인증된 실데이터 검증 결과가 아닙니다.

## 반드시 승인받을 KRX API 네 가지

키 발급만으로 아래 API를 모두 사용할 수 있는 것은 아닙니다.
KRX OpenAPI의 서비스 이용 화면에서 각각 활용신청과 승인을 확인하세요.

| API 이름 | 정식 경로 |
|---|---|
| 유가증권 일별매매정보 | `https://data-dbg.krx.co.kr/svc/apis/sto/stk_bydd_trd` |
| 코스닥 일별매매정보 | `https://data-dbg.krx.co.kr/svc/apis/sto/ksq_bydd_trd` |
| KOSPI 시리즈 일별시세정보 | `https://data-dbg.krx.co.kr/svc/apis/idx/kospi_dd_trd` |
| KOSDAQ 시리즈 일별시세정보 | `https://data-dbg.krx.co.kr/svc/apis/idx/kosdaq_dd_trd` |

- KRX 키는 HTTP 헤더 `AUTH_KEY`로 전달합니다. 날짜 인자는 `basDd=YYYYMMDD`입니다.
- 홈페이지의 **샘플 페이지는 샘플 전용 키만 작동**합니다. 개인 키를 샘플 URL에 넣으면 오류가 날 수 있습니다.
- KRX FAQ에 따르면 데이터는 **영업일 기준 익일 오전 8시**에 갱신됩니다.
  당일 자료·휴일은 비어 있을 수 있어 앱은 최근 16일 안의 직전 제공일을 탐색합니다.
- 시장별 기준일이 다르면 거래대금·상승하락 수를 합쳐 표시하지 않습니다.
- 일부 시장만 조회된 경우 합계의 범위에 조회된 시장만 명시합니다.
- 이 네 API에는 실시간 호가·분봉·외국인/기관 순매수·공매도 데이터가 포함되지 않습니다.

## OpenDART API와 계산 기준

| 용도 | API |
|---|---|
| 6자리 종목코드 → 8자리 기업 고유번호 | `corpCode.xml` (실제 반환 형식은 ZIP 안의 XML) |
| 연결/별도 전체 재무제표 | `fnlttSinglAcntAll.json` |
| 주당현금배당금 | `alotMatter.json` |
| 정기보고서·지분·자사주·증자 등 최근 공시 | `list.json` |

OpenDART 기본 URL은 `https://opendart.fss.or.kr/api`이며 인증키는 `crtfc_key` 인자입니다.

- 최신 제공 분기의 연결재무제표를 우선 사용합니다. 없으면 그 분기의 별도를 선택하고
  과거 비교기간도 **동일한 연결/별도 기준**으로 유지합니다.
- 분·반기 손익계산서의 `thstrm_amount`는 3개월 값입니다. Q4는 연간에서 3분기 누적을 뺍니다.
- **PER · TTM** = 종가 / 최근 연속 4개 분기 공시 기본 EPS 합계.
  분기 자료가 빠졌거나 EPS가 0 이하이면 계산하지 않습니다.
- **PBR 참고값** = 선택 종목의 시가총액 / 지배주주 자본(별도는 자본총계).
  우선주·자기주식 처리 차이 때문에 공식 PBR과 다를 수 있습니다.
- **ROE · TTM** = 최근 연속 4개 분기 지배주주 순이익 / 최근·전년 동기 지배주주 자본 평균.
  별도는 당기순이익과 자본총계를 사용합니다.
- **영업현금흐름**은 표시된 재무기간의 누적 값입니다. ‘3년 연속 양수’는 실제 연간 자료 3개가
  모두 확인되고 양수일 때만 표시합니다.
- **배당수익률**은 표시된 최근 결산연도의 보통주 주당현금배당금 / 종가입니다.
  예측 배당이 아니며, 해당 연도 자료가 없을 때 이전 연도 배당으로 몰래 대체하지 않습니다.
- **RSI**는 Wilder 14일 방식, 거래량 배수는 당일 거래량 / 직전 20거래일 평균입니다.
- 모든 KRX 가격은 **단순주가**입니다. 분할·병합·권리락을 조정하지 않으므로 기술 지표와
  52주 범위 해석에 해당 이벤트를 함께 고려해야 합니다.
- 재무제표는 조회 시점의 정정 자료를 반영합니다. 이 앱은 과거 시점의 정보 가용성을 재현하는
  백테스트 엔진이 아닙니다. 금융업·비표준 계정·일부 우선주/상품은 재무값이 누락될 수 있습니다.
- 공시는 최근 180일 중 접수일 내림차순 최대 100건입니다. 제목 기반 유형 분류와 원문 링크를 제공합니다.
- `—`는 미조회 또는 자료 부족이며 0으로 바꾸지 않습니다. 관심종목 조건검색에서도 누락값은 제외합니다.

## 오류가 발생할 때

| 표시 | 확인할 내용 |
|---|---|
| KRX 401 / 403 | 키, API별 승인, 유효기간, 허용 IP 및 네트워크 차단 |
| OpenDART 010 / 011 / 901 | 등록되지 않거나 중지된 키, 계정 갱신 여부 |
| OpenDART 012 | 실행 PC/서버의 IP 허용 여부 |
| OpenDART 013 | 해당 회사·사업연도·분기의 자료 없음. 통신 오류와 다름 |
| 020 / HTTP 429 | 호출 한도 또는 요청 빈도 제한. 반복 실행을 멈춘 후 확인 |
| NETWORK / TLS | 시간 초과, 방화벽, 보안 프록시, 인증서 또는 PC 시간 |
| FORMAT / ZIP / SCHEMA | JSON 대신 HTML/XML, 손상된 ZIP 또는 응답 명세 변경 |

TLS 인증서 검증을 끄지 않습니다. 일시적 연결 오류/502/503/504는 한 번 재시도하고,
인증 오류나 호출 제한에 대해 무한 반복하지 않습니다. 오류 메시지에는 키와 인증 쿼리 URL을 넣지 않습니다.

KRX는 **시장 전체의 하루 자료**를 날짜별로 조회하는 구조입니다.
따라서 장기간 차트의 첫 로딩에는 수백 건의 호출이 필요할 수 있습니다.
차트에 60일 이동평균 준비 구간도 추가하므로 1M도 1개월보다 많은 날짜를 조회합니다.
결과는 메모리 캐시(KRX 30분 / DART 1시간 / 기업코드 1일)로 재사용합니다.
프로그램 종료 후 캐시는 유지되지 않습니다. 진단 버튼은 현재 상태를 검사하도록 캐시를 비웁니다.

## 검증

```bash
python -m pip install pytest
python -m pytest -q
```

테스트는 키 없이 실행되며 HTTP 오류, ZIP/XML, 날짜 보정, 누락·음수 재무값,
TTM/Q4 계산, RSI, 미리보기, 인증 실패 및 정상 응답 구조의 Streamlit 전체 흐름을 확인합니다.
