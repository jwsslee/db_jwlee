# 이종완의 주식 분석 대시보드 · Pastel Edition 2.0

Python + Streamlit / KRX + 한국투자증권 API / 국내주식 조회 전용.
라벤더·민트·로즈·크림 배경과 청회색/보라색 글씨로 만든 개인 리서치 데스크입니다.
실제 API 값이 없으면 결측으로 표시하며 데모 값으로 대체하지 않습니다.

## Streamlit 배포

- 저장소: `jwsslee/db_jwlee`
- 브랜치: `main`
- 실행 파일: `app.py`
- Python: `3.12`

Streamlit Community Cloud에서 Create app → 저장소/브랜치/실행 파일 지정 → Advanced settings → Secrets를 입력 → Deploy.
기존 `db_test` 앱의 Secrets는 새 앱에 자동 복사되지 않습니다. 동일 변수명으로 새 앱에도 입력하세요.
한 키를 여러 앱에서 동시에 호출하면 합산 호출량/토큰 발급 제한에 영향을 줄 수 있습니다.
코드 업데이트 후 이전 오류가 남으면 앱을 Reboot 하세요.

```toml
KRX_API_KEY = "KRX 인증키"
KIS_APP_KEY = "한국투자증권 App Key"
KIS_APP_SECRET = "한국투자증권 App Secret"
KIS_ENV = "prod"
KIS_CANO = "계좌 앞 8자리"
KIS_ACNT_PRDT_CD = "01"
DASHBOARD_PASSWORD = "직접 정한 충분히 긴 잔고조회 비밀번호"
```

실전은 `prod`, 모의는 `vps`. 키와 계좌 환경을 일치시키세요. 모의에서 지원되지 않는 API가 있을 수 있습니다.
계좌 설정은 잔고 조회에만 필요합니다. 실제 키 파일은 GitHub에 올리지 않습니다.
KRX 유가증권/코스닥 일별매매정보 이용 승인을 확인하세요.
잔고 비밀번호는 증권사 계좌 비밀번호가 아니며 간단한 추가 잠금입니다. 계좌 연결 앱은 비공개로 운영하세요.

## 로컬 실행

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

로컬 키 설정은 `.streamlit/secrets.toml`에 저장합니다. 처음에는 데모 모드이며 사이드바에서 API 연결을 선택합니다.

## 데이터와 계산 기준

- 시세는 KIS의 KRX 시장 코드 J를 사용하는 REST 스냅샷이며 NXT 통합 실시간 스트리밍이 아닙니다.
- 메뉴별로 필요한 데이터를 조회합니다. 시세는 90초, 이력/재무는 30분, KRX는 1시간 캐시합니다.
- 호출 간격 1.1초 이상, 초당 호출 초과/일시적 HTTP 5xx는 제한적으로 재시도합니다.
- 토큰은 메모리에서 재사용합니다. 여러 서버/앱 사이의 토큰·호출 제한은 공유 관리하지 않습니다.
- 모듈 재로딩 시 클래스 식별자를 캐시 키에 포함하여 이전 연결 객체 재사용 문제를 방지합니다.
- KRX는 선택 날짜의 일별자료입니다. 비거래일/미게시일은 이전 거래일을 선택합니다.
- 수급은 장 종료 후 제공되는 순매수 수량(주)이며 금액이 아닙니다. 실제 제공된 날짜만 합산합니다.
- 주가는 수정주가, 주봉은 일봉을 집계합니다. 주봉의 이동평균은 일 단위 평균의 주말 값입니다. 마지막 주는 미완료일 수 있습니다.
- 비교 차트는 모든 성공적으로 조회한 종목/지수의 공통 거래일을 사용합니다. 실패한 종목은 경고 후 제외합니다.
- 수익률 = 마지막 가격 / 시작 가격 − 1. 배당·세금·수수료는 포함하지 않는 가격수익률입니다.
- 연환산 변동성 = 일별 단순수익률 표본표준편차 × √252.
- 최대낙폭 = 표시 기간 중 가격 / 해당 시점까지의 최고 가격 − 1의 최솟값. 전체 상장기간 MDD가 아닙니다.
- 재무표는 연간 자료만 사용합니다. KIS의 분기 손익계산서는 연단위 누적이므로 단일 분기 실적으로 표시하지 않습니다.
- 매출 차트는 최초 제공 연도=100 지수입니다. 영업이익률은 같은 결산기간의 영업이익/매출로 계산합니다.
- PER/PBR은 0 이하를 의미 있는 배수로 표시하지 않습니다. 시세 배수와 재무비율의 기준 시점은 다를 수 있습니다.
- 잔고와 재무표는 연속 조회를 처리합니다. 전체 조회가 실패하면 불완전한 계좌 잔고를 표시하지 않습니다.
- 계좌 잔고는 세션에만 저장하고 공개 데이터 캐시에는 저장하지 않습니다. 비중은 국내주식 평가금액 기준이며 현금 제외입니다.
- 예수금은 주문가능금액과 다릅니다. 입출금/매매/배당 이력이 없어 계좌 누적수익률·지수 대비 계좌수익률은 계산하지 않습니다.
- 알림은 앱 조회 시 화면에 표시하는 조건 점검입니다. 백그라운드 감시·문자·이메일 발송은 없습니다.
- 메모는 세션 종료 시 사라질 수 있으므로 JSON을 다운로드해 보관하세요. 업로드 복원 시 현재 메모를 교체합니다.
- 관심 종목은 최대 8개이며 현재 세션에서 관리합니다. 이름 사전에 없는 종목은 코드로 표시됩니다.
- DART/KIND 공시 링크를 제공하지만 공시 본문·배당 일정·실적 발표일 자동 수집은 하지 않습니다.
- 주문·자동매매 기능은 포함하지 않습니다.
